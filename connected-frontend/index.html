Planner Help

Reference guidance for sequencing training around key activities.

Planning Cycle

The Training Planner follows a three-stage cycle each training year:

  1. Anchor first — Identify all confirmed activities (camps, competitions, inspections, dining-in). These are fixed dates that sessions must work around.
  2. Assign curriculum second — Use the Training Planner to assign curriculum missions to remaining parade nights across the year, balancing cadet levels and instructional load.
  3. Adjust weekly — Review the Parade Night Program and Weekly Program before each night to confirm facilitators, locations, and session order are correct.

How to Use: Training Planner

  1. Select a planning year from the dropdown. The mission table loads automatically.
  2. Use the filters to narrow by cadet level (Orientation, Initial, Junior, etc.) or status (Scheduled / Unscheduled).
  3. Click Assign on any unscheduled mission to open the assignment modal.
  4. Select the parade night, session period (1, 2, or 3), cadet group, and facilitator.
  5. Click Save Assignment. The mission row updates to show the scheduled date.

A mission may be assigned multiple times if it runs across several parade nights (e.g. multi-part modules).

How to Use: Annual Program

  1. Select an existing planning year or click + New Planning Year.
  2. Use Auto-Generate to create parade dates for the year based on a selected weekday. Existing holiday periods are automatically excluded.
  3. The four term blocks show parade count, fill percentage, holidays, and scheduled activities per term.
  4. Add or remove individual parade dates using + Add Date or the Remove button.
  5. To plan next year, use the Rollover action in the Annual Program year header.

How to Use: Parade Night Program

  1. Select a planning year, then select a parade night from the date dropdown.
  2. The grid shows Period 1, Period 2, Period 3 (columns) and cadet groups (rows).
  3. Click any empty cell to add a session. Click a filled cell to edit it.
  4. Assign a facilitator and location for each session.
  5. Timing (start/end times) is drawn from the unit's default timing template.

If timing blocks are missing, confirm a timing template is configured for your unit under Settings.

How to Use: Weekly Program

  1. Select a planning year, then select a parade night.
  2. The weekly program shows all assigned sessions for that night across all cadet groups.
  3. If no sessions have been assigned yet, the page shows "No sessions scheduled for this parade night."
  4. Use this view to confirm the facilitator-facing program before the night.
  5. Print using your browser's print function (Ctrl+P / Cmd+P).

Access Control

  • SQN Admin — full read/write for their own unit
  • Wing Admin / Viewer — read access to all subordinate squadrons
  • National Admin / Viewer — read access across all units
  • SQN General — read-only access to their own unit
  • Auditor — read-only assurance view

Access codes are stored as hashes and are never visible after creation. The backend is the single source of truth for all roles and permissions.
