# Accessibility (WCAG 2.2 AA targets)
Carried from the design system used in prior versions and to be implemented in the React
frontend milestone:
- Themes: light (default), dark, high-contrast, reduced-motion.
- Status = icon + label + colour + shape (never colour alone).
- Visible focus, skip-to-main, no keyboard traps, semantic buttons/links.
- Form labels always visible; errors linked to fields; tables have headers.
- Modals trap focus and close with Escape; print output legible in black and white.
- Colour tokens chosen for ≥4.5:1 normal-text contrast (AAFC palette).
Automated Axe scans and keyboard-only E2E ship with the frontend milestone.
